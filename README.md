# DesarroJoss — Portafolio

Sitio de una sola página (Next.js + TypeScript + Tailwind).

## Desarrollo local

```bash
npm install
npm run dev
```

Abre http://localhost:3000

## Contenido

Todo el contenido (proyectos, stack, enlaces) vive en [`src/app/page.tsx`](src/app/page.tsx). Edítalo ahí directamente para actualizar textos, agregar proyectos o cambiar enlaces.

## Logo

El hero usa el texto `<DJ/>` como logo. Para usar la imagen real del logo, reemplázalo en [`src/app/page.tsx`](src/app/page.tsx) por un componente `next/image` apuntando al archivo del logo dentro de `public/`.

## Deploy

Listo para Vercel o Netlify sin configuración adicional: conecta el repo y despliega (framework preset: Next.js).
